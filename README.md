# Platform Specific Program in C

## Project Description

A simple C program that uses preprocessor directives to identify the operating system on which the program is compiled.

## Features

- Detects Windows
- Detects Linux
- Detects macOS
- Uses conditional compilation
- Demonstrates predefined compiler macros

## Technologies Used

- C
- C Preprocessor
- Conditional Compilation

## How to Run

Compile the program using a C compiler:

```bash
gcc platform_check.c -o platform_check

./platform_check

Operating System: Linux
